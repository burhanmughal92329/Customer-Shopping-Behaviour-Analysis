# 📊 Customer Shopping Behaviour Analysis

An end-to-end **Customer Shopping Behaviour Analysis** project developed using **Python, PostgreSQL, Power BI, and AI-assisted analytics** to transform raw customer transaction data into actionable business insights.

## 🚀 Project Workflow

Customer Dataset Summary → Business Problem Identification → Python-Based Data Preprocessing → SQL Business Insights Analysis → Interactive Power BI Dashboard → Solution to the Business Problem

---

# 📂 Dataset Summary

- **Dataset Size:** 3,900 records × 18 features
- **Purpose:** Analyze customer behaviour, purchasing patterns, and business performance.
- **Key Features:**
  - Customer demographics (Age, Gender, Location, Subscription Status)
  - Purchase details (Category, Item Purchased, Purchase Amount, Season, Size, Colour)
  - Shopping behaviour (Discount Applied, Previous Purchases, Purchase Frequency, Review Rating, Shipping Type)
- **Data Quality:** 37 missing values handled using Python (Pandas).

---

# 🎯 Business Problem

Retail businesses generate large volumes of customer transaction data every day. This project transforms raw data into actionable insights for faster, data-driven decision making.
